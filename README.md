# Lipid-binding-Protein-Recognition-LPR
We developed a multi-label classification model, LPR (Lipid-binding Protein Recognition), that predicts protein-lipid binding abilities based on amino acid sequences. This model utilizes a hybrid framework integrating ESM Cambrian (ESM Team, 2024) and BERT (Devlin et al., 2018).  We also developed two well-curated datasets.
